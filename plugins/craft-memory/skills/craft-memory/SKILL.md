# Craft Memory

Resolve only the smallest task-relevant memory set. Respect project, workspace, task, sensitivity, expiry, provenance, and revocation boundaries. Default to proposing a memory update rather than writing one; never store credentials, raw sensitive content, or an unverified conclusion as durable memory.
