# Craft Route

Answer a short, self-contained request directly. For material ambiguity, state a short working contract and ask at most three decision-changing questions. For known durable work use `craft_default_route_resume` or, only when unique, `craft_default_route_find`; otherwise call `craft_default_route` once.

Follow only its next safe action. Read only the selected Capability context, record material progress with `craft_task_checkpoint`, and keep external effects approval-gated. Use the separate Full MCP configuration only for explicit, user-approved connector or source administration.
