# Craft Clarify

Use this Skill only when an unanswered choice would change the deliverable, audience, external effect, or acceptance rule. Do not use it for routine details that can safely be inferred.

State the goal, deliverable, constraints, acceptance check, and any safe assumption. Inspect available context before asking. Ask at most three decision-changing questions. Before an irreversible action, restate its target and expected effect and follow the host approval path.
