# 学习 Worker 生命周期独立于 Host

学习候选由各自的 Knowledge、Memory、Experience、Notes 链路治理；共享后台调度不共享晋级规则。首期常驻 Worker 由当前用户级 macOS LaunchAgent 托管：craft-context 插件首次有效的 SessionStart 必须幂等地安装或更新并加载它，后续登录恢复待处理候选，Codex/MCP 关闭后继续处理；用户仍可通过 CLI 查询、停止、恢复和卸载。安装冲突、数据根或运行时身份不匹配时必须失败关闭并报告，不得静默覆盖其他服务。候选启用仍由所属子能力的证据、评测、安全和用户确认门槛决定。
