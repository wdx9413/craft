# ADR-0028：公开网页研究保持只读并绑定来源

状态：Accepted（Craft Personal Agent 核心闭环）

## 决策

Craft 的首个个人 Agent 核心闭环支持用户明确委托的公开网页搜索与阅读。该授权只覆盖为当前任务读取公开资料，不覆盖登录或付费页面、读取浏览器中已有的登录态、下载网页附件或可执行文件、提交表单、发送消息或其他对外写入。遇到这些边界时暂停并交给用户决定。

研究结论以 Markdown 文件交付到用户选定的工作目录。事实性结论应带来源链接和访问时间；相互冲突、缺字段或无法核实的内容应显式标出。保存报告不代表来源真实或结论已经被独立验证。

浏览器操作使用 Craft 管理的受限读取能力，沿用既有任务范围、审批和运行回执。产品不依赖第三方助手，也不复用参考项目的代码、SDK 或框架。具体网页搜索与读取实现由工程设计确定，不能要求用户额外申请模型之外的凭据，除非后续单独评估并明确告知。

## 原因

在线研究是首发场景“交代一次，得到带来源成果”的必要部分。只让用户粘贴网址会把资料发现工作重新推回用户；开放登录态、下载和对外操作则超出这项任务所需权限。按任务授权只读公开网页，在两者之间保留了清晰边界。

## 代价与后果

- 公开页面可能缺少数据、存在矛盾或随时间变化，报告必须保留来源和访问时间，并允许标记未知。
- 登录、付费、反爬和动态页面可能无法获取；此时交付部分结果或请用户提供可访问材料，不得伪称资料齐全。
- 公开网页内容按不可信资料处理，不能改变任务指令、权限或审批规则。
- 浏览器读取能力必须有明确的范围、超时、预算、停止和可诊断失败状态；接入外部 Host 不得成为内置助手完成主场景的前提。

## 非目标

- 自动登录、复用用户浏览器的登录态或提取凭据。
- 自动下载网页附件或可执行文件并运行。
- 自动填写并提交表单、发布内容、联系商家或向第三方发送数据。
- 通过该决策宣称价格信息准确、及时或覆盖完整；这些仍需来源证据和独立评测。
