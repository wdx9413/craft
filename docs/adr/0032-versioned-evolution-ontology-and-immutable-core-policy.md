# 本体论可演进，Core Policy 不可自改

状态：Accepted

Craft 的 Evolution Ontology 是跨能力共享、可版本化演进的语义模型；自进化可提出和发布概念、关系、分类器及历史记录分类变更。审批、信任、权限、隐私与安全硬门槛属于 Core Policy，必须由 Runtime 在本体论之外独立执行，自进化不得削弱、替换或绕过。历史事实重分类采用追加版本，保留稳定记录身份、正文、原始来源和旧分类；不确定分类隔离且不改变检索或晋级行为。每类候选在生成前绑定不可由候选修改的 Evaluation Contract；符合预授权范围且通过安全硬门槛、固定指标阈值和分阶段对照评测后自动启用，运行中自动回滚，用户可随时撤销。

本决策取代 ADR-0029 中“概念集合封闭”和“不自动回溯分类”的约束；六个概念仍是当前基线，但可通过版本化本体候选扩展和重新解释。对范围已预授权的自进化候选，本决策取代 ADR-0003 的逐候选 Signoff 要求：通过固定合同后自动分阶段启用，保留人工随时撤销；ADR-0003 对 Core Policy 不可自改的限制继续有效。原记录类型和历史分类仍可按对应 Ontology 版本解释。

## 可检查后果

- Ontology schema、分类规则、关系约束、迁移与分类结果均绑定版本；新版本保留旧版本和迁移回执。
- 对历史记录的重分类只追加语义版本，不覆写正文、稳定 ID、证据来源或旧标签；拆分、合并和内容改写须作为独立候选评测。
- 低置信或多义结果进入 unresolved 状态，不影响当前检索、冲突处理和晋级；高置信也必须满足候选所属 Evaluation Contract。
- Evaluation Contract 冻结基线/候选版本、样例与环境、主指标、退化容忍范围和安全断言。候选不得修改合同、样例或门槛。安全、权限、隐私与数据治理失败是硬拒绝，不参与收益加权。
- 候选按隔离回放/影子评测、小范围、项目级、全局逐段自动发布；各段独立验收，越界自动回滚，用户可随时撤销。
- Core Policy 的权威实现不得从 Ontology 动态取得可放宽的值；Runtime 必须独立校验并失败关闭。
