# 分流标签

技能使用五个规范分流角色。此文件将角色映射到本仓库本地 Markdown 议题跟踪中使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此议题 |
| `needs-info` | `needs-info` | 等待报告者提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 已完全规范，可交给 Agent |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不予处理 |
