# Workbench Experience Projection (v0.12.10; v0.12.9 baseline)

> v0.12.9 established the read-only experience projection. v0.12.10 adds Project Brain, Trace, and long-task checkpoint routes. It remains a local console projection, not a native desktop shell.

`WorkbenchExperienceKernel` is a read-only product projection. It joins launches, Trace events, outcomes, artifacts, and the next safe action by project, task, or Work Session. Replay plans contain only action digests and references; they require revalidation and never execute an external action.
