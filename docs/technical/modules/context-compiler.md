# Context Compiler：有界知识上下文

v0.11.30 将 Knowledge Claim 编译为某次任务可用的上下文，而不是把整个 Wiki 或向量命中直接塞给模型。

1. 只考虑 `reviewed`、未过期且作用域匹配的 Claim。
2. 默认用可复算的关键词与结构化范围排序；未配置时不发出向量请求。
3. 受 `max_items` 与 `max_chars` 双重预算约束；每条落选材料都标记为未审核、过期、范围不符、未匹配或预算不足。
4. 返回的正文携带 Claim ID、精确版本和 Evidence 引用；持久 Bundle 只保存摘要、引用、预算和选择原因，不复制上下文正文。

Embedding 可以成为未来显式配置的候选排序器，但不能改变审核/过期/范围门禁，也不能成为知识的唯一存储或唯一解释。
