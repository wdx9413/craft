# 数据目录维护备份与暂存恢复

停止使用该数据空间的 Craft、Host Hook 和 Worker 后，再执行维护命令。备份会对发现的 SQLite 数据库获取无等待的写入保留锁，任一库繁忙就失败，不在备份期间阻塞重试。此写入围栏不替代文件系统快照或阻止非协作进程修改正文，因此命令也会校验文件摘要和清单漂移。

```sh
CRAFT_DATA_DIR=/absolute/data craft storage-backup --output /absolute/new-backup
craft storage-restore --backup /absolute/new-backup --output /absolute/new-restored-staging
```

输出目录的父目录必须已存在；输出目录本身必须不存在，并位于源目录之外。命令拒绝符号链接、特殊文件和不安全清单路径。新目录权限为 0700。备份覆盖主库、项目/会话分库及普通正文文件；SQLite 使用 backup API 合入已提交 WAL，再将备份副本归一为独立日志模式。清单保存逐文件字节数与 SHA-256，恢复同时验证清单、摘要及 SQLite quick_check。最多 100,000 个文件，恢复清单最大 16 MiB。

恢复不会覆盖现有目录。失败时清理此次创建的输出目录，不删除备份源。生成的目录是**暂存恢复**：已有记录可能含原路径引用，必须在停机状态放回输出中的 original_root 后再启用。保留原数据目录用于回退，不同时启动原目录和恢复副本。跨数据根的路径迁移仍需独立迁移工具与验收；本命令不批量替换内部绝对路径。

这是一致性维护备份，不是加密备份或异地灾备。包含实际业务正文和配置，按原数据同等级保护。清单摘要用于检测内容变化，不是可信签名，也不授予知识或发布准入。
