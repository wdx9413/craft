# 业务结果指标合同（候选）

本合同定义可比较的观测，不宣称当前已采集数据或已经产生业务收益。每次报告固定指标定义版本、时间窗口、环境、Host 和模型的精确版本或摘要、预算、来源、数据保留期限及删除责任人；缺失项标记为未知，不参与可比性结论。只保留随机化关联标识、版本摘要、必要的计数和结果回执；默认不上传任务原文、文件、凭据或原始轨迹。回执需有来源、观察者、时间与保留期限，不能仅凭被测方自述认定独立结果。

| 指标与版本 | 分子 / 分母 | 排除与来源 | 比较与解释 |
|---|---|---|---|
| 完成耗时 v1 | 配对任务中从约定开始到独立验收完成的耗时；分母为两组均有有效结果的任务对数 | 排除预先定义的无效任务和环境故障，分别报告数量及原因；来源为独立计时与验收回执 | 同任务、同环境和预算比较基线与候选，分别报告未完成数；耗时降低不能单独证明质量不变 |
| 独立验收通过率 v1 | 独立验收通过的任务数 / 所有符合条件的任务数 | 排除规则预先冻结并披露；缺失结果不得算通过；来源为独立验收回执 | 以配对基线比较并报告任务数、失败及缺失；验收者不得仅依据被测方自报 |
| 策略决定 v1 | 各决定（允许、拒绝、待审批）次数 / 已评估请求数 | 记录未知和未评估请求；来源为策略决定回执 | 描述策略行为，不代表实际执行效果 |
| 已观察效果 v1 | 实际效果符合授权范围的请求数 / 有独立效果观察的已执行请求数 | 无法观察的执行单列；来源为独立执行／效果回执 | 与策略决定分开报告；覆盖范围和缺失数必须同时列出 |
| 审批误放行 v1 | 经独立复核确定不应允许且被允许的请求数 / 独立复核的全部不应允许请求数 | 未复核和结论不确定请求单列；来源为审批决定与独立复核回执 | 分母为零时记为不可计算，不记为零风险 |
| 撤销成功率 v1 | 在约定期限内经独立验证生效的撤销数 / 符合条件的撤销请求数 | 未验证、超时和失败分别列出；来源为撤销及效果验证回执 | 撤销请求已记录不等于效果已撤销 |

比较前应冻结任务集合、配对方法、排除条件、验收标准和分析窗口；披露样本量、缺失与偏差。Token、Trace、测试覆盖率、一次成功运行只是技术观测，不能单独推导用户收益或因果关系。合成夹具、真实 Host 观测和业务准入分开标注；不得由本合同或单份 Eval 报告自动授权或更改路由。
