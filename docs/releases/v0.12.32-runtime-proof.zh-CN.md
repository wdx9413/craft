# v0.12.32：Runtime Proof & Distribution 收口

本轮保持版本 `0.12.32`，补齐本地单 Agent/Codex 控制台的两条基础闭环：

- `RuntimeProofKernel` 将环境声明、探测、边界检查、Attestation 和恢复前环境重水合统一为摘要账本；未验证隔离、缺少凭据 Broker 或环境漂移均失败关闭。
- `McpTaskKernel` 提供先持久化、owner 隔离、TTL、轮询状态、取消和幂等的 MCP Task 生命周期；正文不会写入 Task 记录。
- 真实模型仍由用户显式配置并探测，CI 不联网、不保存 API Key；真实业务质量不能由 Fixture 测试冒充。
- SQLite 仍是本地事实源；Trace 冷数据、JSONL/OTLP 和外部对象存储继续通过 Adapter 接入。

已验证：新增 Runtime Proof 与 MCP Task 专项测试、TypeScript 类型检查、全量分支覆盖率门禁、核心/插件构建和 MCP 握手。未在本轮宣称企业多租户、远程控制、多 Agent 净收益或真实业务效果。
