# Craft 0.12.68

本版本将 Codebase 的仓库分析数据和评测结果隔离到各项目的 `.craft_data/codebase/`，并改进任务式检索与 Go 关系识别。

## 变更

- 仓库快照、图分片和分析缓存保存在被分析项目的数据目录；Git 忽略规则写入私有 `.git/info/exclude`，不改项目 `.gitignore`。
- 检索评测以不可变 JSON 保存到项目 `evaluations/` 目录，包含仓库修订、评测套件摘要、召回指标和关系精确率/召回率。
- 增加中文任务词到代码动作的检索提示，并限制 Go 接口实现关系到有效符号。
- 恢复跨平台适配器构建流程。

## 验证

- 评测覆盖 Craft TypeScript、D-Simu Python、Kefu JavaScript、D-Forge Java、is-manager Go；五份报告对应同一 Craft 源码改动摘要，均达到各自固定套件的 `evaluation_pass` 门槛。
- 所有仓库的调用图和影响分析金标准均通过；大型仓库的完整关系图仍报告为 `partial`。
- 模块增量覆盖率、类型检查、构建和插件包检查以本次发布记录为准。
