# v0.12.31 发布前报告

## 已实现

- `MemoryGovernanceKernel`：Candidate/Review/Ledger、scope、默认 TTL、冲突仲裁、过期扫描、会话摘要 digest。
- `WorkflowDagKernel`：DAG/JSON Schema 形状校验、循环与副作用校验、受控 JSON 投影、step checkpoint、resume drift、cancel/replan、Evaluation/Canary 生命周期门禁。
- `TaskStateKernel`：append-only `task_state_event`、revision projection、Evidence/actor/reason、并发冲突拒绝与 replay。
- 旧库迁移：仅通过 `scripts/import-legacy-knowledge.ts` 一次性离线读取 `data/pages/**`，confirmed 筛选、摘要/digest、candidate 导入、去重、Evidence 绑定、审核发布、撤回/tombstone、source diff 与失败报告；运行时 MCP/Host 不再扫描旧目录。
- Studio API、MCP surface、Internal Host 会话持久化均走受控 Kernel；旧 Memory 表增加敏感内容拒绝，兼容投影不作为新 Studio 写入目标。
- 包、插件清单、README 和适配器元数据统一为 `0.12.31`。
