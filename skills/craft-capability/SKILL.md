# Craft Capability

Discovery is not activation, authorization, or invocation. Prefer digest-based logical deduplication while preserving every source provenance. Return a small ranked candidate set and explain health, trust, effects, cost, and compatibility. Do not install, disable, authorize, or execute a capability unless the user separately requests it.
